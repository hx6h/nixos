# hx6h/nixos

Modular NixOS + Home Manager configuration. The `rewrite/dwm-qs-monomodern` branch is being prepared for a low-overhead dwl + Quickshell desktop.

The intended profile uses one monochrome palette, Quickshell for the bar/launcher/control center, and avoids running parallel bar/launcher/notification daemons. Review the branch before switching systems.
