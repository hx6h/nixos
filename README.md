# hx6h/nixos

Modular NixOS + Home Manager configuration.

## dwm_qs-monomodern

A lightweight dwl + Quickshell desktop profile. Quickshell provides the floating monochrome bar, app launcher, notification center, control center, and wallpaper. The palette is shared from `modules/home/colors.nix`. The profile avoids parallel Waybar, Rofi, Mako, swaybg, and Hyprpaper processes.

Changes are on `rewrite/dwm-qs-monomodern`, not `main`. Review and build the configuration before switching your live system.
